# TikTok Video Utility

Aplikasi web modern berbasis **Next.js 15 (App Router)** dan **TypeScript** untuk memeriksa metadata serta menampilkan embed resmi video TikTok.

## 🚀 Panduan Deploy ke Vercel

1. **Extract ZIP file ini** ke folder komputer Anda.
2. Push ke **GitHub** atau jalankan `vercel` via CLI.
3. Tambahkan Environment Variable di Vercel:
   - `NEXT_PUBLIC_SITE_URL` = `https://nama-proyek-anda.vercel.app`
